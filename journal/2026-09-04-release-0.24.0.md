# Release 0.24.0

## Contexte

Depuis `v0.23.0`, Arclith a reçu deux fonctionnalités publiques complémentaires :

- le mapping relationnel structuré PostgreSQL de la PR #212, sans changement du port
  `Repository[T]` ni migration automatique ;
- le scaffold métier guidé de la PR #213, avec association d'entité interactive ou explicite et
  replay de recette rétrocompatible.

## Décision

- publier `arclith` en `0.24.0` ;
- publier `arclith-cli` en `0.21.0` ;
- relever la dépendance minimale de la CLI à `arclith>=0.24.0` ;
- conserver la stratégie PostgreSQL `generic_json` par défaut ;
- documenter `--entity ShoppingItem` dans le smoke test consommateur afin qu'il reste entièrement
  non interactif.

Un incrément mineur est retenu pour les deux distributions : le framework ajoute une surface
relationnelle publique opt-in et la CLI ajoute un nouveau parcours de génération, sans rupture des
contrats existants.

## Impact

- API publique : nouveaux types relationnels déjà livrés par la PR #212 ;
- CLI : nouveaux choix de scaffold déjà livrés par la PR #213 ;
- données : aucune migration automatique, les applications gardent la responsabilité du schéma ;
- dépendances de production : aucune nouvelle dépendance ;
- déploiement : aucun déploiement applicatif, publication PyPI uniquement.

## Validation prévue

- `make precommit` et `make coverage` ;
- suite complète `arclith-cli` et smoke test du scaffold ;
- build strict de la documentation ;
- vérification des locks et des deux distributions ;
- `twine check` des wheels et sdists ;
- publication depuis le tag signé `v0.24.0`, puis installation sans cache depuis PyPI dans un
  environnement consommateur isolé.
