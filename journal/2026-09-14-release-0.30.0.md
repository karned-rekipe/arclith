# Release 0.30.0

## Contexte et décision

La PR #239 livre #222, première phase de l'EPIC #221 : un blueprint append-only
distinct du CRUD, son contrat runtime et son adapter mémoire de référence.
Les retours Copilot ont été corrigés et les conversations résolues avant fusion.

- publier `arclith` en `0.30.0` et `arclith-cli` en `0.27.0` ;
- imposer `arclith>=0.30.0` à la CLI pour que les nouveaux contrats générés soient
  disponibles dans un consommateur frais ;
- conserver les fixtures qui testent des dépendances de projets plus anciens ;
- utiliser le tag signé commun `v0.30.0` et les deux Trusted Publishers existants ;
- ne modifier ni les protections GitHub ni les credentials PyPI.

## Pilotage

À la demande de l'utilisateur, le board Arclith #5 est réouvert et Sprint 7 couvre
le 14 au 20 septembre 2026 (7 jours). #221 reste In Progress, #222 est Done après
fusion de #239. Les dix itérations historiques sont conservées.

## Validation prévue

Precommit, complexité, couverture, suite CLI complète, MkDocs strict, construction
et inspection des wheels/sdists, PR de release et review thread-aware. Après
fusion et tag signé : vérifier les deux publications publiques PyPI puis installer
sans cache un service append-only neuf, exécuter ses tests et le scénario
append/duplicate/conflict. Aucun déploiement de microservice n'est inclus.
