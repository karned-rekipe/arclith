# Release 0.27.0

## Contexte

Les PR #220 et #227 ajoutent une nouvelle abstraction de scaffold : le CRUD devient un blueprint
applicatif explicite, indépendant des adapters, puis peut être projeté vers FastAPI dans une étape
séparée. Le choix `crud` ne prétend pas couvrir tous les comportements métier et n'impose ni
persistence durable ni équivalent mécanique pour MCP, RabbitMQ ou LangGraph.

Le workflow de publication du dépôt construit toujours les deux distributions depuis un tag
commun. Même si cette itération porte principalement sur le scaffold, la release conserve ce
contrat public et synchronise la version minimale du framework utilisée par les projets générés.

## Décision

- publier `arclith` en `0.27.0` ;
- publier `arclith-cli` en `0.24.0` ;
- relever la dépendance minimale de la CLI à `arclith>=0.27.0` ;
- utiliser le tag commun signé `v0.27.0`, qui déclenche les deux Trusted Publishers PyPI.

## Impact

- application : génération optionnelle des cinq use cases CRUD, de leur composition et de leurs
  tests à partir d'un manifeste de feature canonique ;
- API : projection FastAPI explicite et atomique avec contrats Pydantic, routes, presenters et
  traductions d'erreurs dédiées ;
- architecture : la notion de CRUD reste au niveau applicatif ; les adapters ne font que projeter
  une feature existante selon la sémantique de leur transport ;
- données : repository mémoire par défaut pour tester la feature, aucune persistence durable ni
  migration automatique ;
- déploiement : aucun déploiement applicatif, publication des deux distributions PyPI uniquement.

## Validation prévue

- suites complètes framework et CLI, couverture minimale à 90 %, Ruff, mypy, Bandit et MkDocs
  strict ;
- génération d'un projet CRUD neuf, projection FastAPI, synchronisation des dépendances et tests
  du consommateur ;
- construction et inspection des wheels et sdists des deux distributions ;
- PR de release, merge, tag signé `v0.27.0` et suivi des deux jobs Trusted Publisher ;
- vérification directe des versions PyPI puis installation sans cache dans un environnement isolé.
