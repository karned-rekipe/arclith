# Release Arclith 0.22.0

## Contexte

La release `0.21.0` précède les dernières livraisons de la roadmap #57 : embedding OpenAI,
vector-store provider-neutral, adapter Qdrant et POC locaux OpenTelemetry, Vault et Keycloak.

## Décisions

- publier une version mineure `arclith 0.22.0` pour les nouvelles capabilities publiques ;
- publier `arclith-cli 0.19.0` pour les nouveaux adapters exposés dans le catalogue ;
- aligner le scaffold, les tests, les exemples et les locks sur `arclith>=0.22.0` ;
- conserver la publication sans token statique via les deux Trusted Publishers PyPI du workflow
  `publish.yml`.

## Validation locale

- `make precommit` : Ruff, mypy et Bandit passent ;
- `make coverage` : 1 833 tests passent, 5 sont ignorés et la couverture atteint 90,64 % ;
- `cd cli && uv run --frozen pytest -q` : 148 tests passent et 1 est ignoré ;
- `make docs` : le site MkDocs est construit sans erreur ;
- `uv lock --check` passe à la racine et dans `cli/` ;
- les wheels et sdists `arclith` et `arclith-cli` sont construits, puis validés par
  `twine check`.

La review Copilot, le merge, le tag signé `v0.22.0`, la GitHub Release et les deux
publications PyPI sont les contrôles de livraison effectués après ce commit.
