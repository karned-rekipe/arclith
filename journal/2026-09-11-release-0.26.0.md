# Release 0.26.0

## Contexte

La PR #218 complète le scaffold incrémental publié en `v0.25.0` avec des contrats réellement
fonctionnels de bout en bout : composition partagée, bindings typés, routage FastAPI sans doublon,
adapters optionnels et arborescence fermée pour les développeurs comme pour les agents de codage.
La revue Copilot a ensuite identifié des cas limites sur les constructeurs, les imports aliasés,
les manifestes persistés et le layout historique ; ils sont tous corrigés et couverts par des
régressions avant cette release.

## Décision

- publier `arclith` en `0.26.0` ;
- publier `arclith-cli` en `0.23.0` ;
- relever la dépendance minimale de la CLI à `arclith>=0.26.0` ;
- utiliser le tag commun signé `v0.26.0`, qui déclenche les deux Trusted Publishers PyPI.

La publication conjointe garantit que les projets générés utilisent le framework qui expose les
contrats d'entité, les imports lazy et les comportements runtime validés par le nouveau scaffold.

## Impact

- framework : imports des transports optionnels, contrats d'entité et repositories alignés avec
  la génération incrémentale ;
- CLI : FastAPI, FastMCP, LangGraph et RabbitMQ composent les mêmes instances applicatives ;
- architecture : les blueprints et les guides embarqués ferment explicitement les emplacements
  autorisés sans générer de feature ou de provider fictif ;
- données : aucune migration automatique ; MongoDB reste opt-in et n'ajoute aucun adapter memory ;
- déploiement : aucun déploiement applicatif, publication des deux distributions PyPI uniquement.

## Validation prévue

- suites complètes framework et CLI, couverture minimale à 90 %, Ruff, mypy, Bandit et MkDocs
  strict ;
- projet consommateur neuf avec appels FastAPI et FastMCP et partage du repository vérifié ;
- construction et inspection des wheels et sdists des deux distributions ;
- PR de release, relecture de toutes les conversations, merge, tag signé `v0.26.0` et suivi des
  deux jobs Trusted Publisher ;
- vérification directe des versions PyPI puis installation sans cache dans un environnement isolé.
