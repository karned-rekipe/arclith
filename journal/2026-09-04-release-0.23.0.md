# Release 0.23.0

## Contexte

La roadmap channel #169 livre un contrat provider-neutral, un adapter mémoire,
un webhook HTTP générique et Slack Events API. Ces ajouts étendent aussi le
catalogue et les projets générés par `arclith-cli`.

## Décision

- publier `arclith` en `0.23.0` ;
- publier `arclith-cli` en `0.20.0` ;
- relever la dépendance minimale de la CLI à `arclith>=0.23.0` ;
- conserver Telegram, Email et Microsoft Teams dans le backlog différé.

Un incrément mineur est retenu pour les deux distributions, car la release
ajoute une nouvelle surface publique sans rupture des contrats existants.

## Validation prévue

- `make precommit` et `make coverage` ;
- suite complète `arclith-cli` ;
- build strict de la documentation ;
- vérification des locks et des deux distributions ;
- publication depuis le tag signé `v0.23.0`, puis installation dans un
  environnement consommateur isolé.
